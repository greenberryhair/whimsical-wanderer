# Whimsical Wanderer — JCink Want Ad Template Pack

Version: 1.0

GitHub Pages target: `https://greenberryhair.github.io/whimsical-wanderer/`
Package date: 2026-08-18

This folder contains the Whimsical Wanderer single-character and
multiple-character want ads, CSS, artwork, sample silhouettes,
JCink-ready HTML, and browser previews.

## Quick install

1. Upload this entire folder to a static host.
2. Copy the public URL of the uploaded `whimsical-wanderer` folder.
3. Open `jcink/INSTALL-CSS.txt`.
4. Replace `https://greenberryhair.github.io/whimsical-wanderer` with your URL.
5. Put both @import lines at the TOP of the JCink site's stylesheet.
6. Members can then copy the HTML from `jcink/single-want-ad.html`
   or `jcink/multiple-want-ad.html` into their posts.
7. To self-host the portrait/card image URLs too, use the files ending
   in `-selfhost.html` and replace the same example base URL inside them.

changes as v2 so existing posts on other sites do not unexpectedly change.
