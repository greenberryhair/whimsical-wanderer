JCink installation

Upload this folder, then replace the example host with your public URL. Put these imports at the top of the JCink stylesheet:

@import url("https://greenberryhair.github.io/whimsical-wanderer/assets/css/single-v1.css");
@import url("https://greenberryhair.github.io/whimsical-wanderer/assets/css/multiple-v1.css");

Self-host every image

The packaged CSS already loads its artwork locally. For image URLs written directly into the JCink HTML, use the files ending in -selfhost.html and replace the example host URL.

Safe updates

Keep the v1 CSS stable after other sites begin using it. Publish future visual revisions as v2 so old posts remain unchanged.

Cormorant Garamond is loaded from Google Fonts; font files are not bundled.
